# 페이지 역할 하달문 (오케스트레이터용)

## 공통 전제
- 기준 디자인은 `ORCHESTRATION/STITCH_REDESIGN_MASTER_PLAN.md`를 따른다.
- 기능 로직은 유지하고 UI/UX만 리디자인한다.
- 각 워크트리는 자신의 페이지 역할만 수정하고 계약 변경이 필요하면 체크인에 명시한다.

## 1) foundation
목표: 전체 사용자 여정의 뼈대 연결
작업:
- 랜딩/대시보드에서 진단 진입 CTA 고정
- 상단/좌측 네비에서 핵심 페이지 이동 보장
- 공통 상태 뱃지/카드/버튼 컴포넌트 표준화
- Stitch 홈/디자인시스템 시안을 기준으로 공통 헤더, KPI 카드, 스텝 진행바 리디자인
- 공통 Empty/Error/Loading 패턴을 동일 톤으로 정리
산출물:
- 라우트 맵 문서 + 공통 컴포넌트 목록

## 2) diagnosis
목표: 스킬 진단 결과를 추천으로 넘길 수 있는 구조 확정
작업:
- 질문/응답/점수 구조 정식화
- 카테고리별 갭 요약 데이터 생성
- 추천 페이지 전달 payload 스키마 문서화
- Stitch 진단/결과 시안을 기준으로 질문 카드, 하단 액션, 결과 리포트 섹션 구조 리디자인
- 결과 화면에 종합 점수, 강점/보완 역량, 추천 CTA 위계를 명확히 반영
산출물:
- `diagnosis-result contract` (필드명/타입)

## 3) recommendation
목표: 진단 결과 기반 추천 경험 완성
작업:
- 추천 카드 + 추천 이유 칩(역량갭 근거)
- 필터(난이도/시간/직무) + 정렬
- "신청하기" CTA를 과정연동 페이지로 연결
- Stitch 추천 시안 기준으로 카드 썸네일 비중 축소, 추천 근거 텍스트 강화
- 상단 요약 바에 추천지수/추천과정수/현재 기준역량을 노출
산출물:
- 추천 목록 화면 + 빈상태/오류상태

## 4) course-linking
목표: 추천 -> 신청 전환률 중심 플로우
작업:
- 과정 상세에서 신청 링크 연결
- 외부 이동 파라미터 정의
- 신청 후 복귀 동선 정의
- Stitch 과정 상세 시안을 기준으로 학습목표, 커리큘럼, 기대효과, 우측 신청 패널을 재구성
- 외부 이동 안내는 유지하되 전환 마찰을 줄이는 카피로 개선
산출물:
- 링크 매핑표 + 이동 시나리오

## 5) history
목표: 학습 성과 추적
작업:
- 진단 결과 이력 타임라인
- 수강 현황 요약(진행/완료)
- 성장 포인트 카드
- Stitch 이력 시안을 기준으로 KPI 카드, 성장 타임라인, 집중 강화 역량, 이력 테이블을 재정렬
- 잠금/프로토타입 문구를 실제 상태 기반 액션으로 교체
산출물:
- 이력 대시보드 MVP

## 6) chatbot
목표: 사용자 맥락 기반 보조 가이드
작업:
- "내 부족 역량", "추천 이유" 빠른 질문 버튼
- 답변에서 추천/이력 페이지 링크 제공
- Stitch 챗봇 시안 기준으로 좌측 요약, 중앙 대화, 우측 팁 패널의 3열 구조 확정
- 빠른 질문 버튼과 추천 카드 삽입형 답변 UI를 실제 제품 톤으로 정리
산출물:
- 3턴 이상 대화 시나리오

## 7) responsive
목표: 전 페이지 반응형 품질 보증
작업:
- 1440/1024/768/390 체크리스트 수행
- 깨짐/오버플로우/탭 접근성 보정
- Stitch 데스크톱 시안이 모바일에서 어떤 카드 우선순위로 접히는지 규칙화
- 하단 액션 바, 표, 3열 레이아웃의 축소 규칙 정의
산출물:
- 해상도별 QA 리포트
