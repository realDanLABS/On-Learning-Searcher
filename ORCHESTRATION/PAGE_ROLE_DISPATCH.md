# 페이지 역할 하달문 (오케스트레이터용)

## 1) foundation
목표: 전체 사용자 여정의 뼈대 연결
작업:
- 랜딩/대시보드에서 진단 진입 CTA 고정
- 상단/좌측 네비에서 핵심 페이지 이동 보장
- 공통 상태 뱃지/카드/버튼 컴포넌트 표준화
산출물:
- 라우트 맵 문서 + 공통 컴포넌트 목록

## 2) diagnosis
목표: 스킬 진단 결과를 추천으로 넘길 수 있는 구조 확정
작업:
- 질문/응답/점수 구조 정식화
- 카테고리별 갭 요약 데이터 생성
- 추천 페이지 전달 payload 스키마 문서화
산출물:
- `diagnosis-result contract` (필드명/타입)

## 3) recommendation
목표: 진단 결과 기반 추천 경험 완성
작업:
- 추천 카드 + 추천 이유 칩(역량갭 근거)
- 필터(난이도/시간/직무) + 정렬
- "신청하기" CTA를 과정연동 페이지로 연결
산출물:
- 추천 목록 화면 + 빈상태/오류상태

## 4) course-linking
목표: 추천 -> 신청 전환률 중심 플로우
작업:
- 과정 상세에서 신청 링크 연결
- 외부 이동 파라미터 정의
- 신청 후 복귀 동선 정의
산출물:
- 링크 매핑표 + 이동 시나리오

## 5) history
목표: 학습 성과 추적
작업:
- 진단 결과 이력 타임라인
- 수강 현황 요약(진행/완료)
- 성장 포인트 카드
산출물:
- 이력 대시보드 MVP

## 6) chatbot
목표: 사용자 맥락 기반 보조 가이드
작업:
- "내 부족 역량", "추천 이유" 빠른 질문 버튼
- 답변에서 추천/이력 페이지 링크 제공
산출물:
- 3턴 이상 대화 시나리오

## 7) responsive
목표: 전 페이지 반응형 품질 보증
작업:
- 1440/1024/768/390 체크리스트 수행
- 깨짐/오버플로우/탭 접근성 보정
산출물:
- 해상도별 QA 리포트
