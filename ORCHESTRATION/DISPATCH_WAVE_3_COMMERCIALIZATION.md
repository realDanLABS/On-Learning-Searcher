# Dispatch Wave 3: Commercialization Drive

## 공통 지침
- 이번 웨이브 목표는 기능 추가 자체보다 `여정의 설명력`, `반복 사용성`, `운영 전환성` 강화다.
- 기능 로직은 이미 연결되어 있으므로, 각 워크트리는 자신의 범위 안에서 사용자가 "다음에 무엇을 해야 하는지" 더 명확히 느끼게 만들어야 한다.
- 계약 필드 변경이 필요하면 반드시 체크인 문서에 먼저 기록한다.
- 모든 작업은 `진단 -> 추천 -> 신청 -> 성장 추적` 흐름 안에서 읽혀야 한다.
