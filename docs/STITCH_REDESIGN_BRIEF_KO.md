# On Learning Searcher Stitch 리디자인 브리프

## 프로젝트 개요

On Learning Searcher는 현대위아 내부 학습 추천 및 역량 진단 플랫폼이다.  
현재 디자인의 완성도는 높지만, 전체 서비스 톤을 한 단계 더 전문적이고 현대적인 B2B 학습 플랫폼 수준으로 끌어올리고 싶다.

## 목표

현재 구현된 모든 페이지의 정보구조와 핵심 UX 흐름은 유지하면서, 2026년 기준 최신 엔터프라이즈 SaaS 및 AI 제품 디자인 트렌드를 반영한 상위 버전의 디자인 시안을 생성해 달라.

## 가장 중요한 제약

1. 현재 페이지의 기능 구조는 유지할 것
2. 화면별 주요 문구와 정보의 위계는 유지할 것
3. 지금의 브랜드 방향성과 전문성은 유지하되, 더 정교하고 밀도 있게 개선할 것
4. 랜딩페이지처럼 과장된 마케팅 톤으로 바꾸지 말 것
5. 관리자 페이지는 실제 운영도구처럼 보여야 하며, 테이블/폼/상태관리 UX를 강화할 것
6. 모바일과 데스크톱 모두 고려할 것
7. 과한 장식, 과한 3D, 과한 글래스모피즘, 과한 네온 스타일은 지양할 것

## 유지하고 싶은 현재 장점

1. 직관적인 흐름
2. 명확한 섹션 구분
3. 학습 추천과 진단 흐름의 연결성
4. 관리자 페이지의 실무형 구조
5. 비교적 신뢰감 있는 톤

## 개선하고 싶은 방향

1. 전체 타이포그래피 시스템을 더 정교하게
2. 카드, 테이블, 차트, 필터, 상태 배지의 시각적 일관성 강화
3. 헤더, 사이드 네비게이션, 페이지 타이틀 영역의 정보 밀도 개선
4. 엔터프라이즈 SaaS에 맞는 고급스러운 여백과 정렬 체계 강화
5. 진단 결과, 추천, 러닝패스, 관리자 대시보드의 전문성 강화
6. 단순히 예쁜 UI가 아니라 실제 제품처럼 보이는 화면으로 개선

## 원하는 스타일 키워드

- Enterprise AI platform
- Premium SaaS dashboard
- Professional Korean B2B product
- Clean but information-dense
- Modern product system
- Trustworthy
- Operational clarity
- Refined interaction hierarchy

## 피하고 싶은 스타일

- 소비자용 라이프스타일 앱 같은 느낌
- 지나치게 캐주얼한 색상 체계
- 과한 애니메이션 중심 UI
- 의미 없는 대형 히어로 섹션
- 마케팅 랜딩페이지 중심 구성
- 게임풍, 웹3풍, 네온풍, 과장된 미래주의 UI

## 화면 범위

다음 페이지들의 디자인 시안을 각각 또는 하나의 통합 시스템으로 재구성해 달라.

1. 홈
2. 역량 진단
3. 진단 결과
4. 추천 과정
5. 학습 경로
6. 과정 상세 / 수강 신청 연결
7. 학습 이력
8. 분석 대시보드
9. 챗봇 상담
10. 플랫폼 소개
11. 관리자 대시보드
12. 관리자 부서 분석
13. 관리자 문항 관리
14. 관리자 과정 관리
15. 관리자 회원 관리
16. 관리자 공지 / FAQ
17. 관리자 시스템 설정

## 디자이너에게 기대하는 결과

1. 전체 서비스 공통 디자인 시스템 방향 제안
2. 사용자용 화면과 관리자용 화면의 시각적 차별화 전략
3. 핵심 페이지에 대한 고도화된 리디자인 시안
4. 카드, 표, 필터, 네비게이션, 배지, 상태표현 방식 개선안
5. 2026년 기준으로 낡아 보이지 않는 제품 수준의 UI 제안

## 추가 요청

현재 스크린샷을 단순히 미화하지 말고, 제품 전략 관점에서 더 설득력 있는 구조와 시각적 우선순위를 제안해 달라.  
다만 기존 기능과 콘텐츠 구조가 크게 바뀌어 개발 반영이 어려워지는 방향은 피하고, 현실적으로 프론트엔드에 재적용 가능한 수준의 리디자인으로 제안해 달라.
