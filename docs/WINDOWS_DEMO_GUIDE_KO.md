# On Learning Searcher 윈도우 시연 가이드

## 1. 시연 구성 개요

이 프로젝트는 하나의 서버에서 아래 두 화면을 함께 운영합니다.

- 학습자 페이지: `/`
- 관리자 페이지: `/admin`

시연 모드에서는 관리자 페이지가 임시로 바로 열리도록 설정되어 있습니다.

- 학습자 페이지 상단/하단의 `관리자` 버튼 클릭 시 바로 관리자 페이지 진입
- `/admin` 직접 접속 시에도 회원가입 없이 관리자 세션 자동 생성

관리자 시연 계정 정보는 아래와 같습니다.

- 사원번호: `90000`
- 비밀번호: `local-dev-only`

주의:

- 현재 시연 모드에서는 관리자 경로에 들어가면 자동으로 관리자 세션이 세팅됩니다.
- 시연 종료 후 실제 운영용으로 전환할 때는 이 모드를 다시 꺼야 합니다.

## 2. 회사 윈도우 PC 준비물

필수:

- 윈도우 PC
- 이 프로젝트 폴더 전체
- Node.js LTS

권장:

- Chrome 최신 버전
- 압축 해제 도구

## 3. 회사 PC로 옮겨야 할 것

아래 폴더 전체를 그대로 복사하는 것이 가장 안전합니다.

- 프로젝트 루트 전체

특히 빠지면 안 되는 것:

- `src`
- `public`
- `scripts`
- `package.json`
- `package-lock.json`
- `next.config.mjs`
- `tsconfig.json`

권장 복사 위치 예시:

```text
C:\demo\On_Learning_Searcher
```

## 4. 가장 쉬운 실행 방법

프로젝트 루트 안에 시연용 배치 파일이 있습니다.

실행 파일:

- [windows-demo-preview.bat](/Users/daniel/내%20작업/내%20프로젝트/Vibe%20Coding/On_Learning_Searcher/scripts/windows-demo-preview.bat)

윈도우에서 실행 순서:

1. 프로젝트 폴더를 연다
2. `scripts\windows-demo-preview.bat`를 더블클릭한다
3. 처음 실행이면 `npm install`이 자동으로 진행된다
4. 이어서 `npm run build`가 자동 실행된다
5. 마지막으로 시연 서버가 `3000` 포트에서 실행된다
6. 브라우저가 자동으로 `http://127.0.0.1:3000`를 연다

## 5. 수동 실행 방법

배치 파일이 막히는 경우 아래 순서로 직접 실행하면 됩니다.

### 5-1. 명령 프롬프트 열기

1. `Win + R`
2. `cmd`
3. Enter

### 5-2. 프로젝트 폴더로 이동

예시:

```bat
cd /d C:\demo\On_Learning_Searcher
```

### 5-3. 의존성 설치

```bat
npm install
```

### 5-4. 빌드

```bat
npm run build
```

### 5-5. 시연 서버 실행

```bat
npm run start
```

### 5-6. 브라우저 접속

같은 PC에서:

- [http://127.0.0.1:3000](http://127.0.0.1:3000)

## 6. 시연 시작 전 권장 준비

브라우저 상태가 이전 테스트 때문에 꼬였을 수 있으니 시연 직전에는 아래 중 하나를 권장합니다.

방법 A:

- 크롬 시크릿 모드로 접속

방법 B:

- 기존 브라우저에서 사이트 데이터 삭제

방법 C:

- 관리자 페이지의 `시스템 설정`에서 운영 데이터 초기화 사용

권장 시연 전 초기 진입:

1. 브라우저 열기
2. [http://127.0.0.1:3000](http://127.0.0.1:3000) 접속
3. 학습자 페이지부터 시연

## 7. 권장 시연 순서

### 7-1. 학습자 페이지 시연

권장 순서:

1. 홈(`/`) 진입
2. 상단 메뉴 확인
3. `역량 진단` 진입
4. 진단 문항 진행
5. 결과 화면 확인
6. `추천 과정 보러가기`
7. 추천 과정 확인
8. 학습 경로/과정 선택 흐름 확인
9. `나의 학습` 페이지 확인
10. 챗봇/상담 흐름 확인

### 7-2. 관리자 페이지 시연

학습자 페이지 상단 또는 하단의 `관리자` 버튼 클릭

시연 포인트:

1. 대시보드
2. 부서 분석
3. 문항 관리
4. 과정 관리
5. 회원 관리
6. 공지 / FAQ
7. 시스템 설정

중요:

- 시연 모드에서는 `관리자` 버튼을 누르면 바로 관리자 페이지 진입 가능
- 회원가입 과정이 필요 없음

## 8. 시연 중 보여주기 좋은 핵심 포인트

### 학습자 페이지

- 홈에서 관리자/학습자 흐름이 같은 서버에서 연결됨
- 진단 -> 추천 -> 과정 선택 -> 나의 학습 -> 챗봇 흐름이 하나로 이어짐
- UI가 실제 학습 여정처럼 연결되어 있음

### 관리자 페이지

- 관리자 상단/하단 크롬이 학습자 페이지와 한 서비스처럼 이어짐
- 문항/과정/회원/공지 관리 페이지가 한 묶음으로 작동
- 시스템 설정에서 스냅샷/초기화/빠른 이동 시연 가능

## 9. 문제 발생 시 체크리스트

### 브라우저가 안 열릴 때

- 주소창에 직접 입력:
  - `http://127.0.0.1:3000`

### `3000` 포트가 이미 사용 중일 때

이미 다른 서버가 떠 있으면 기존 터미널을 찾아 `Ctrl + C`로 종료 후 다시 실행하세요.

### `npm install` 실패

확인할 것:

- 인터넷 연결
- Node.js 설치 여부
- 명령 프롬프트를 일반 사용자 권한이 아닌 기본 권한으로 다시 실행

### 관리자 페이지가 바로 안 열릴 때

아래 순서로 확인:

1. 주소창에 `http://127.0.0.1:3000/admin`
2. 새로고침
3. 시크릿 모드에서 다시 접속

### 데이터 상태가 엉켜 보일 때

아래 중 하나 사용:

- 크롬 시크릿 모드
- 사이트 데이터 삭제
- 관리자 `시스템 설정`에서 데이터 초기화

## 10. 시연 종료 방법

시연 서버를 띄운 터미널 창에서:

```text
Ctrl + C
```

한 번 더 물으면:

```text
Y
```

## 11. 가장 추천하는 실제 시연 방식

가장 안정적인 방식:

1. 회사 PC에 프로젝트 전체 복사
2. Node.js 설치
3. `scripts\windows-demo-preview.bat` 실행
4. 크롬 시크릿 모드로 `http://127.0.0.1:3000` 접속
5. 학습자 페이지부터 시연
6. 학습자 페이지의 `관리자` 버튼으로 관리자 페이지 바로 이동

이 방식이면:

- 학습자/관리자 모두 하나의 서버
- 별도 회원가입 없이 관리자 시연 가능
- 진단부터 추천까지 실제 흐름 시연 가능
- 관리자 설정/운영 화면까지 자연스럽게 연결 가능
